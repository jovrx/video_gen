# RunningHub H3 视频生成系统

用户已确认 FastAPI + SQLite + 网页方案，KEY 将稍后配置。API 事实与来源见 ../../runninghub-api-research.md。

交付一个本地运行的网页应用，接收有序参考图、提示词和秒数，异步提交指定工作流，展示状态、当前节点和可获得的节点进度，最终预览和下载视频。无 KEY 时网页可使用配置和任务查看功能，提交返回明确配置错误，不调用平台。

后端由配置、工作流映射、RunningHub 客户端、持久化任务库、进度解释器、任务管理器和 HTTP/SSE API 构成。数据存入 data，KEY 仅存环境变量。前端原生 HTML/CSS/JS，部署无需 Node 构建。单进程、单 worker。

工作流 API JSON 可从文件导入或认证拉取。参数映射使用显式节点 ID/字段，支持固定图片槽、数组和 ZIP 批量输入；不自动猜测。未使用槽位必须显式提供空值，否则禁止少图提交，避免使用模板参考图。最大图数、最小图数和时长由映射配置声明，不能将别的模型限制当作本工作流事实。

SQLite 保存 taskId、阶段、节点快照、结果和错误。提交结果未知时不自动重试；重启只恢复有 remote taskId 的监控。创建前记录 submitting，以避免崩溃后重复提交。WSS 作为增量进度来源，V2 查询作为状态和输出来源，旧 outputs 仅兼容获取 WSS。WS 中断、查询暂时失败不会重提任务。TASK_END webhook 暂不实现，首版轮询可在本地运行。

视频下载到本地，通过后端路由预览和下载。远端成功但无视频、下载失败显示独立状态，允许仅重试下载。网页刷新后可查看既有任务。轮询不中断长任务；不承诺 ETA 或时间百分比。节点百分比仅在事件上报时展示。

验证映射顺序与空槽、JSON/ZIP、时长类型、长 ID、RunningHub 错误和协议边界、缓存/任务事件过滤、任务重启恢复、提交超时不重提、图片真实性及大小验证、本地视频结果选择和浏览器表单交互。真实付费生成等待 KEY 与节点映射就绪。
